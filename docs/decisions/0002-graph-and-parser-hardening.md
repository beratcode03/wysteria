# ADR 0002: Graph and Parser Hardening

## Decision

For Phase 2.1, Wysteria hardens its DAG verification, parser boundary defenses, structural cardinality
limits, and node semantic contracts:

1. **Iterative Kahn's Algorithm**: Replaces recursive DFS cycle detection with an iterative Kahn
   topological sort. Tie-breaking among nodes with zero in-degree uses lexicographical ID ordering to
   guarantee deterministic topological ordering. It eliminates stack overflow / `RecursionError`
   vulnerabilities on deep linear graphs (1000+ nodes).
2. **Parser Boundary Defenses**: The JSON depth counter forbids negative depth values (preventing
   underflow attacks via unmatched closing delimiters) and rejects unclosed strings before decoding.
3. **Structural Cardinality Limits**: Explicit limits are enforced (`MAX_NODES = 500`,
   `MAX_EDGES = 1000`, `MAX_INPUTS = 100`, `MAX_OUTPUTS = 100`, `MAX_ASSERTIONS = 200`,
   `MAX_CAPABILITIES = 50`) using diagnostic code `WYS104` to reject oversized documents before
   deep validation.
4. **Complete Node and Assertion Semantics**:
   - `SelectConfig.path` is strictly validated against the RFC 6901 JSON Pointer specification.
   - `TransformNode` enforces output type parity according to the operation (e.g. `to_integer` must
     produce integer/number, `to_string` and string cases must produce string).
   - `ConstructNode` templates are scanned for `{var}` and `${var}` placeholders, verifying all
     referenced inputs are declared in `node.inputs`.
   - `AssertNode` and top-level `workflow.assertions` validate predicate/expected compatibility
     (`exists` forbids expected values; `type_is` requires valid `ValueType` names).
   - `OutputNode` requires a single `"value"` input with compatible type parity.

## Rationale

Untrusted workflow documents (generated by LLMs or external systems) can attempt adversarial DoS
through recursion bombs, delimiter underflow, or cardinality bloat. Hardening the verification engine
at the structural, graph, and semantic boundaries ensures the trusted core remains secure, deterministic,
and crash-proof.
